# Zero-Trust Encrypted File Sharing Platform

A secure web-based file sharing platform built using the Zero Trust security approach. The application enables authenticated users to upload, access, and manage files securely through encryption and access-control principles.

## Features

* Secure user authentication
* Encrypted file sharing
* File upload and download functionality
* Access control for authorized users
* Database-based user and file management
* Simple and responsive user interface
* Zero Trust approach for protecting sensitive files

## Technologies Used

* **Backend:** Python, Flask
* **Frontend:** HTML, CSS, JavaScript
* **Database:** SQLite
* **Security:** Encryption, authentication, and access control

## Project Structure

```text
Zero-Trust-Encrypted-File-Sharing-Platform/
│
├── app.py              # Main Flask application
├── app.js              # Frontend JavaScript
├── index.html          # Main web page
├── style.css           # Styling file
├── uploads/            # Local uploaded files (not uploaded to GitHub)
└── database.db         # Local database file (not uploaded to GitHub)
```

## How to Run the Project

1. Clone this repository:

```bash
git clone https://github.com/PMKHARE786/Zero-Trust-Encrypted-File-Sharing-Platform.git
```

2. Open the project folder:

```bash
cd Zero-Trust-Encrypted-File-Sharing-Platform
```

3. Install the required Python packages:

```bash
pip install flask cryptography
```

4. Run the application:

```bash
python app.py
```

5. Open this address in your browser:

```text
http://127.0.0.1:5000
```

## Security Note

The database file and uploaded user files are intentionally excluded from this repository to protect user data and sensitive information.
